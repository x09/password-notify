# Локализация password-notify

Используется GNU gettext, домен `password-notify`, кодировка UTF-8.
Английский — язык исходных строк и запасной вариант при отсутствии перевода.
Локаль выбирается через `setlocale(LC_ALL, "")`: LC_ALL имеет приоритет над
LC_MESSAGES и LANG для сообщений. Русская локаль, например ru_RU.UTF-8,
выбирает русский каталог. GNU gettext также учитывает LANGUAGE;
при локали C/POSIX перевод не включается.

## Каталоги и сборка

- `po/en.po`, `po/ru.po` — английский и русский каталоги.
- `po/password-notify.pot` — шаблон исходных строк.
- `locale/<язык>/LC_MESSAGES/password-notify.mo` — результат сборки.

Нужны msgfmt, xgettext и msgmerge из gettext-tools в ALT Linux.
Обычный `make` собирает оба MO с `msgfmt --check --check-format`.

```sh
make translations
# После изменения строк в C:
make pot
msgmerge --update po/en.po po/password-notify.pot
msgmerge --update po/ru.po po/password-notify.pot
# Заполнить переводы и проверить записи fuzzy:
make translations
```

Непроверенные записи fuzzy и пустые переводы не становятся рабочими переводами.
Не меняйте только msgid в PO: исходная строка в C и msgid должны совпадать.
Сначала измените строку в коде, затем обновите POT и оба PO.

## Форматные строки и сообщения сервера

Динамические имена пользователей, числа и коды ошибок не зашиваются в перевод.
Например, `Password changed successfully via kpasswd for %s` получает
текущий principal при выполнении. Форматные параметры должны сохраняться
в переводе; формы день/дня/дней выбираются через ngettext.

Известные ответы Kerberos/PAM/LDAP переводятся внутри приложения.
Поддерживаются все 13 клиентских сообщений из `source4/kdc/kpasswd-helper.c`
Samba 4.21, включая короткие варианты: история паролей, минимальная длина,
сложность, запрет смены, неизвестный пользователь, ошибки TGT и результат смены.
Полная таблица находится в разделе локализации [README_ru.md](README_ru.md).

Числа минимальной длины и глубины истории извлекаются из ответа сервера.
В исходнике Samba соответствующие шаблоны используют %d, а в gettext-каталогах
приложения — %s, поскольку подставляется извлечённая строка числа.
Значения 7 и 24 не фиксированы. В `Failed to set password: %s` код
вроде NT_STATUS_ACCESS_DENIED сохраняется. Неизвестные диагностические сообщения
остаются в исходном виде.

Добавление msgid в PO само по себе не переводит произвольный ответ сервера:
для нового сообщения нужно добавить распознавание в `src/i18n.c`,
шаблон gettext, переводы и проверку в `tests/test_i18n.c`.
Samba на сервере изменять не требуется.

Дочерний passwd запускается с LC_ALL=C для стабильного распознавания запросов
в псевдотерминале. Перевод применяется к полученному результату.
Пароли не предназначены для вывода в сообщения или журнал и не передаются
как аргументы passwd.

## Поиск каталогов и установка

Программа сначала проверяет `locale/` рядом с реальным исполняемым файлом
(путь определяется через /proc/self/exe). Если каталога нет, используется
LOCALEDIR, заданный при сборке: по умолчанию `/usr/local/share/locale`,
при PREFIX=/usr — `/usr/share/locale`.
Существующий каталог рядом с бинарником имеет приоритет, даже если он пуст.

Для установки используйте одинаковые PREFIX и вариант трея:

```sh
# MATE/XFCE:
make clean
make PREFIX=/usr USE_STATUS_ICON=1
# От root:
make install PREFIX=/usr USE_STATUS_ICON=1
```

Для AppIndicator (KDE/GNOME) используйте USE_STATUS_ICON=0 на обоих этапах.
При переносе неустановленной сборки сохраните рядом с бинарником `locale/`
и `icons/`. Для установки переводов в RPM оба spec перечисляют en/ru MO в %files.

## Проверка

```sh
LC_ALL=ru_RU.UTF-8 LANGUAGE= ./password-notify -h
LC_ALL=en_US.UTF-8 LANGUAGE=en ./password-notify -h
LC_ALL=C LANGUAGE= ./password-notify -h
make USE_STATUS_ICON=1 build/test-i18n translations
LC_ALL=ru_RU.UTF-8 LANGUAGE= ./build/test-i18n "$PWD/locale" ru
LC_ALL=C LANGUAGE= ./build/test-i18n "$PWD/locale" en
```

Указанные UTF-8 локали должны быть установлены. Полный `make USE_STATUS_ICON=1 test`
дополнительно требует Python 3, Xvfb/xvfb-run и systemd-analyze.
Тесты локализации проверяют формы множественного числа, переменные ограничения
политики, ответы Samba и сохранение неизвестной диагностики.

После смены локали графического сеанса повторите `password-notify -a`, чтобы
обновить окружение менеджера. Уже работающий GUI-процесс требует перезапуска.

## Иконки и описание

В трее нет текста рядом с иконкой. GtkStatusIcon показывает состояние
во всплывающей подсказке; для AppIndicator передаются заголовок и описание,
их показ зависит от панели. Красный ключ означает оставшиеся дни <= warn_days,
включая истёкший пароль. Вне предупреждения управляемый процесс завершается,
поэтому постоянно видимого чёрного ключа между проверками нет.

SVG устанавливаются в PREFIX/share/password-notify/icons.
Описание «О программе» локализовано; проект: https://github.com/x09/password-notify.
